# Agentic SDLC: Building a Software Factory

A hands-on course where you build a suite of AI agents that automate every phase of the software development lifecycle — from requirements and architecture through testing, deployment, and Git workflow. By the end, you have a working "software factory": a coordinated set of agents that can take a feature idea and carry it to production.
